# Prompt Memo

Edgeで、よく使うAIプロンプトを保存・検索・貼り付けできる拡張機能です。

## インストール

1. Edgeで `edge://extensions/` を開く
2. 左側の「開発者モード」をオンにする
3. 「展開して読み込み」を押す
4. このフォルダー（`PromptMemo`）を選択する

ツールバーの拡張機能一覧から Prompt Memo をピン留めすると、いつでもすぐ開けます。

## 使い方

- `＋` でプロンプトを追加
- 新規追加時、同じタイトルのプロンプトが存在する場合は追加を停止（既存データとJSONインポートの重複は許容）
- 検索欄でタイトル・本文・タグを検索
- `★` でお気に入りに登録
- 起動時は「お気に入り」を表示し、「その他」ではお気に入り以外を表示
- 削除確認と全件インポート確認は「今後は確認を省略する」を個別に設定可能
- ヘッダーの「確認設定」から、各確認画面をいつでも再び表示可能
- AIサイトの入力欄にカーソルを置き、「入力欄に貼り付け」をクリック
- 入力欄へ挿入できないページでは、自動的にクリップボードへコピー
- `Ctrl+Shift+P` でもポップアップを開けます
- 画面下部の「エクスポート」で、全件を `backup-ext_PromptMemo_YYYY-MM-DD_hhmm.json` としてダウンロードフォルダーへ保存
- 画面下部の「インポート」で、エクスポートしたJSONを読み込み
- 画面下部の「クラウド設定」からSupabaseに接続すると、複数のPCで同期し、上書き前の内容を履歴として残せます

## JSONファイル

- `backup-ext_PromptMemo_YYYY-MM-DD_hhmm.json`：すべてのプロンプトを含むエクスポートファイル。インポートすると現在の一覧を置き換えます。

エクスポートファイルは自動更新されません。「エクスポート」を押した場合だけ新しいファイルが作成されます。プロンプトの追加・編集・削除や、JSONのインポートでは変更されません。

通常の保存先には `chrome.storage.local` を使います。閲覧データの削除や拡張機能の削除に備え、必要なタイミングで「エクスポート」を押してJSONファイルを保存してください。

ブラウザの「ダウンロード前に各ファイルの保存場所を確認する」が有効な場合、バックアップのたびに保存確認が表示されることがあります。

## クラウド同期とバックアップ（Supabase）

TodoMemoと同じ仕組みで、Supabaseを正本、`chrome.storage.local` をその手元のコピーとして扱います。ログインしていれば、追加・編集・削除のたびに自動でクラウドへ保存され、**上書きされる直前の内容は必ず履歴として残ります**。

### 準備

1. Supabaseでストレージのバケット（既定は TodoMemo と同じ `todo-backups`）を用意し、ログインするユーザーが自分のフォルダー（`{ユーザーID}/`）を読み書きできるポリシーを設定する
2. 拡張機能の「クラウド設定」に、プロジェクトURL・anonキー・バケット名を入力して保存する
3. 「ログイン」にSupabaseのメールアドレスとパスワードを入力する

接続先が `https://*.supabase.co` 以外（独自ドメイン）の場合は、`manifest.json` の `host_permissions` にそのドメインを追加してください。

### 保存される場所

TodoMemoと同じバケットを共有できるよう、ファイル名にアプリ名が入ります。

- `{ユーザーID}/PromptMemo-latest.json`：クラウド上の最新の全プロンプト
- `{ユーザーID}/PromptMemo-history/`：上書きされる直前の内容（履歴）

### 履歴の残り方と戻し方

- クラウドが上書きされるたびに、上書き前の内容を1件ずつ保管します
- 直近30件はすべて残し、それより古いものは1日1件で最大30日分を残します
- 「クラウド履歴」から、件数と日時を見て任意の時点に戻せます
- 戻す操作も「新しい版」として記録するため、他のPCも安全に追従します

### 取り違えを防ぐしくみ

- クラウドの版（リビジョン）を基準に更新するため、古いPCが新しい内容を上書きすることはありません
- 他のPCの変更と手元の未同期の変更が食い違うときは、どちらを残すか確認します。選ばなかった方も履歴へ退避します
- プロンプトが半分以上減る変更（ブラウザーデータの削除や誤操作など）は、確認するまでクラウドへ反映しません
- ログアウト中の変更はこのPCだけに保存され、次回ログイン時に上記の手順で照合されます

ポップアップを閉じた直後の変更が送信されなかった場合も、次にポップアップを開いたときに自動で送信されます。
