# Prompt Memo

Edgeで、よく使うAIプロンプトを保存・検索・貼り付けできる拡張機能です。

## インストール

1. Edgeで `edge://extensions/` を開く
2. 左側の「開発者モード」をオンにする
3. 「展開して読み込み」を押す
4. このフォルダー（`PromptMemo`）を選択する

ツールバーの拡張機能一覧から Prompt Memo をピン留めすると、いつでもすぐ開けます。

## 使い方

- `＋` でプロンプトを追加
- 新規追加時、同じタイトルのプロンプトが存在する場合は追加を停止（既存データとJSONインポートの重複は許容）
- 検索欄でタイトル・本文・タグを検索
- `★` でお気に入りに登録
- 起動時は「お気に入り」を表示し、「その他」ではお気に入り以外を表示
- 削除確認と全件インポート確認は「今後は確認を省略する」を個別に設定可能
- ヘッダーの「確認設定」から、各確認画面をいつでも再び表示可能
- AIサイトの入力欄にカーソルを置き、「入力欄に貼り付け」をクリック
- 入力欄へ挿入できないページでは、自動的にクリップボードへコピー
- `Ctrl+Shift+P` でもポップアップを開けます
- 画面下部の「エクスポート」で、全件を `backup-ext_PromptMemo_YYYY-MM-DD_hhmm.json` としてダウンロードフォルダーへ保存
- 画面下部の「インポート」で、エクスポートしたJSONを読み込み

## JSONファイル

- `backup-ext_PromptMemo_YYYY-MM-DD_hhmm.json`：すべてのプロンプトを含むエクスポートファイル。インポートすると現在の一覧を置き換えます。

エクスポートファイルは自動更新されません。「エクスポート」を押した場合だけ新しいファイルが作成されます。プロンプトの追加・編集・削除や、JSONのインポートでは変更されません。

通常の保存先には `chrome.storage.local` を使います。閲覧データの削除や拡張機能の削除に備え、必要なタイミングで「エクスポート」を押してJSONファイルを保存してください。

ブラウザの「ダウンロード前に各ファイルの保存場所を確認する」が有効な場合、バックアップのたびに保存確認が表示されることがあります。
