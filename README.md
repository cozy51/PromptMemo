# Prompt Memo

よく使うAIプロンプトを保存・検索・コピーできるWebアプリです。ビルド不要の静的サイトなので、Vercelなどにそのまま配置できます。

> v2.0.0 でEdge拡張機能からWebアプリに移行しました。拡張機能からの移行方法は「[拡張機能からの移行](#拡張機能からの移行)」を参照してください。

## 公開（Vercel）

1. Vercelで「Add New… → Project」からこのリポジトリをインポートする
2. Framework Preset は **Other** のまま、Build Command・Output Directory は空欄（既定）でデプロイする
3. 発行されたURL（例：`https://prompt-memo.vercel.app`）を開く

- `vercel.json` で、セキュリティ用のヘッダー（CSPなど）を付けています。Supabase への接続は `https:` 宛てのみ許可しています
- `.vercelignore` で、テスト（`scripts/`）・マニュアル（`output/`）・使っていないアイコンは公開対象から外しています
- クリップボードへのコピーは HTTPS（またはlocalhost）でのみ動作します。Vercelは標準でHTTPSです

### 手元で動かす

Node.js（18以上）が必要です。追加のパッケージはありません。

```
npm install
npm run dev
```

表示された `http://localhost:3000/` をブラウザで開きます（`vercel.json` と同じヘッダーを付けて配信するので、本番と同じ条件で確認できます）。ポートを変えるときは環境変数 `PORT` を指定します。

`index.html` をファイルとして直接開くと、クリップボードやクラウド同期が動かない場合があります。

## 使い方

- `＋` でプロンプトを追加
- `＋短文` で、本文1行だけの「短文」を登録（単語登録のように、例：「200字程度で要約してください。」）。タイトル・説明は不要で、本文がそのままカードの見出しになります。改行は空白にまとめ、同じ短文の重複登録は停止
- 「短文」タブで短文だけを一覧表示。短文の「編集」から内容の変更・削除が可能
- 新規追加時、同じタイトルのプロンプトが存在する場合は追加を停止（既存データとJSONインポートの重複は許容）
- 検索欄でタイトル・本文・タグを検索
- `★` でお気に入りに登録
- 「コピー」でプロンプトをクリップボードへコピーし、AIサイトの入力欄に貼り付けて使います
- 起動時は「履歴」を表示。コピーしたプロンプトを、使った日時とともに新しい順に最大30件並べます
- 「お気に入り」はお気に入りのみ、「その他」ではお気に入り以外を表示
- 使用履歴はこのブラウザだけに保存し、クラウドへは同期しません（コピーのたびにクラウドの履歴が増えないようにするため）
- 削除確認と全件インポート確認は「今後は確認を省略する」を個別に設定可能
- ヘッダーの「確認設定」から、各確認画面をいつでも再び表示可能
- 画面の幅に合わせてカードを横に並べます（スマートフォンでは1列）
- 同じブラウザで複数のタブを開いている場合、どのタブで編集しても他のタブに反映されます
- 画面下部の「エクスポート」で、全件を `backup-web_PromptMemo_YYYY-MM-DD_hhmm.json` としてダウンロード
- 画面下部の「インポート」で、エクスポートしたJSONを読み込み（拡張機能版のエクスポートファイルも読み込めます）
- 画面下部の「クラウド設定」からSupabaseに接続すると、複数の端末で同期し、上書き前の内容を履歴として残せます
- クラウド設定済みでログアウトしているときは、画面全体が暖色（ベージュ／オレンジ）になり、同期していないことが分かるようにしています

### 拡張機能版との違い

- 「貼り付け」（開いているページの入力欄へ直接挿入）は、Webページからは他のタブを操作できないため廃止し、「コピー」のみになりました
- ショートカットキー（`Ctrl+Shift+P`）はありません。ブックマークやピン留めしたタブから開いてください

## 拡張機能からの移行

拡張機能のデータ（`chrome.storage.local`）はWebアプリからは読み取れないため、次のどちらかで移します。

- **クラウド同期を使っていた場合**：Webアプリで「クラウド設定」に同じ接続先を入れてログインすると、クラウドの内容が読み込まれます。拡張機能側に未同期の変更が残っていないよう、先に拡張機能で「今すぐ同期」しておいてください
- **クラウド同期を使っていなかった場合**：拡張機能で「エクスポート」し、Webアプリで「インポート」します

移行が終わったら、拡張機能は `edge://extensions/` から削除できます。

## JSONファイル

- `backup-web_PromptMemo_YYYY-MM-DD_hhmm.json`：すべてのプロンプトを含むエクスポートファイル。インポートすると現在の一覧を置き換えます（拡張機能版の `backup-ext_…` も同じ形式です）。

エクスポートファイルは自動更新されません。「エクスポート」を押した場合だけ新しいファイルが作成されます。プロンプトの追加・編集・削除や、JSONのインポートでは変更されません。

### インポート前の確認

全件インポートは現在の一覧を置き換えるため、実行前に内容を比べて表示します。

- 「現在」と「ファイル」を並べて、**最終更新の日時**と、**プロンプト・お気に入り・タグの件数**（増減つき）を表示
- ファイルが現在のデータより古い場合は強い警告を出し、「古い内容で上書きし、それ以降の変更が失われることを確認しました」にチェックするまでインポートできません
- 件数が半分以上減る場合や、日時を読み取れないファイルの場合も理由を表示します
- 「今後は全件インポート時の確認を省略する」を設定していても、古いファイル・件数が大きく減るファイル・日時が読めないファイルでは必ず確認します

通常の保存先には、ブラウザの `localStorage`（このサイト専用の保存領域）を使います。データはブラウザ・端末ごとに別々で、閲覧データ（Cookieとサイトデータ）を削除すると消えます。クラウド同期を使うか、必要なタイミングで「エクスポート」を押してJSONファイルを保存してください。

ブラウザの「ダウンロード前に各ファイルの保存場所を確認する」が有効な場合、エクスポートのたびに保存確認が表示されることがあります。

## クラウド同期とバックアップ（Supabase）

TodoMemoと同じ仕組みで、Supabaseを正本、ブラウザの `localStorage` をその手元のコピーとして扱います。ログインしていれば、追加・編集・削除のたびに自動でクラウドへ保存され、**上書きされる直前の内容は必ず履歴として残ります**。

### 準備

1. Supabaseでストレージのバケット（既定は TodoMemo と同じ `todo-backups`）を用意し、ログインするユーザーが自分のフォルダー（`{ユーザーID}/`）を読み書きできるポリシーを設定する
2. Webアプリの「クラウド設定」に、プロジェクトURL・anonキー・バケット名を入力して保存する
3. 「ログイン」にSupabaseのメールアドレスとパスワードを入力する

接続先・anonキー・ログイン状態は、このブラウザの `localStorage` に保存されます（anonキーは公開前提のキーです。データの保護はSupabase側のポリシーで行います）。共用PCでは使用後にログアウトしてください。

### 保存される場所

TodoMemoと同じバケットを共有できるよう、ファイル名にアプリ名が入ります。

- `{ユーザーID}/PromptMemo-latest.json`：クラウド上の最新の全プロンプト
- `{ユーザーID}/PromptMemo-history/`：上書きされる直前の内容（履歴）

### 履歴の残り方と戻し方

- クラウドが上書きされるたびに、上書き前の内容を1件ずつ保管します
- 直近30件はすべて残し、それより古いものは1日1件で最大30日分を残します
- 「クラウド履歴」から、件数と日時を見て任意の時点に戻せます
- 戻す操作も「新しい版」として記録するため、他の端末も安全に追従します

### 取り違えを防ぐしくみ

- クラウドの版（リビジョン）を基準に更新するため、古い端末が新しい内容を上書きすることはありません
- 他の端末の変更と手元の未同期の変更が食い違うときは、どちらを残すか確認します。選ばなかった方も履歴へ退避します
- プロンプトが半分以上減る変更（ブラウザーデータの削除や誤操作など）は、確認するまでクラウドへ反映しません
- ログアウト中の変更はこのブラウザだけに保存され、次回ログイン時に上記の手順で照合されます

ページを閉じた直後の変更が送信されなかった場合も、次にページを開いたときに自動で送信されます。
